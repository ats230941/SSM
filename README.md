# Home Inventory & Smart Shopping Manager 🛒🌱

A fully static, privacy-first Progressive Web Application (PWA) designed to track household inventory, analyze historical purchase data, compare store pricing, and minimize personal waste.

---

## 💡 Project Purpose & Motivation

This project was born out of a desire to live **more frugally, mindfully, and sustainably**. 

By tracking exact inventory quantities, expiration dates, and historic store pricing, this tool helps eliminate:
* **Impulse Spending:** Knowing exactly what is already in stock prevents unnecessary purchases.
* **Food & Household Waste:** Expiration alerts ensure items are used before they spoil.
* **Overpaying:** Detailed price tracking ensures purchases are made at the lowest price points across stores.

---

## 🚀 Key Features

* **Offline-First Storage:** All data stays local in your browser using **IndexedDB**—no server, external database, or login required[cite: 1].
* **Inventory Tracking:** Real-time stock levels, low-stock alerts, and expiration date warnings[cite: 1].
* **Price History & Comparison:** Track store-by-store pricing trends to find the best shopping locations[cite: 1].
* **Shopping Lists:** Smart list creation with estimated costs based on historical purchase data[cite: 1].
* **Automation-Ready:** Built to support receipt parsing, OCR input, and custom Python/AI pipelines[cite: 1].

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, Modern JavaScript (ES Modules)[cite: 1]
